# ChatBot 搭建

这个教程主要分为三个部分，一个是获取大模型 API，一个是搭建知识库，一个是搭建聊天流

点击新建 API 密钥即可得到 API（硅基流动中的这个 API 对于所有模型来说都是一样的，具体计费的时候会看你使用的是什么模型）

点击设置

### Fouth 知识库处理设置

直接的 md 文档事实上并不适合检索，我们需要对文档的内容分段，将文件拖入后，于是有下面的界面：

#### 分段设置

这是文本分段方式，下面介绍一下通用分段和父子分段

- **通用分段：**将文章内容按照段落划分，每个段落有一些由 Dify 自动生成的关键词，当用户输入一段文本的时候，模型会提取关键词，用这些关键词去检索知识库，将关键词相同的分块返回，作为模型回复时的资料参考，也就是召回的块
- **父子分段：**将文本的内容按照父段和字段划分，父段包含子段，当检索的时候会检索字段的内容，但是在返回的时候会返回整个父段的内容，这样模型就可以获得完整的上下文，这里我推荐父子分段。

分段最大长度和分段重叠长度依据需要设置即可

#### 索引方式

也就是模型检索文件的方式，这里推荐高质量，因为直接拿关键词匹配准确度非常低，下面的 Embedding 模型就是对文本处理的模型，这个模型的作用是处理文本，我们使用 API 里面提供的模型即可。

![Dify 教程截图](https://ChasePassion.github.io/picx-images-hosting/Dify教程/15.6bhbejfzlb.webp)

#### 检索设置

![Dify 教程截图](https://ChasePassion.github.io/picx-images-hosting/Dify教程/16.wisw418z5.webp)

这里推荐混合检索，根据你的知识库的类型选择权重设置和 Rerank 模型，设置 Top K 和 Score 阈值，这里我的设置是 Rerank 模型，Top K 设置为 10，Score 不开启。Rerank 可以保证模型看到的第一个信息是最相关的，下面的两个设置可以保证模型得到的信息全面不会遗漏。
