# ChatBot Setup

This tutorial is mainly divided into three parts: obtaining a large model API, building a knowledge base, and building a chat flow.

## Large Model API

Large model API is the foundation of AI applications. Using API, we can use the model corresponding to this API. So how to obtain the model's API? We can use SiliconFlow (https://cloud.siliconflow.cn/models)

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/1.77dstzf7np.webp)

The square shows the APIs supported by SiliconFlow. Below, we click on the API Key on the left.

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/2.64e3j3k5ul.webp)

Click on "Create New API Key" to get the API (this API in SiliconFlow is the same for all models, and the specific billing will depend on which model you use).

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/3.7zqobpz90v.webp)

After clicking and entering remarks, click "Create Key", copy the obtained API key, and return to Dify.

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/4.175mp99or7.webp)

Click Settings.

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/5.23244pjx31.webp)

Click on "Model Providers" on the left, slide down to the "Install Model Provider" interface, and install the model provider you need. Here we install SiliconFlow. Since I have already installed it, I will not demonstrate it here. After installation, in the **To be configured** list, click "Settings", enter the API Key, and the model will be configured successfully.

### Fourth Knowledge Base Processing Settings

Direct md documents are actually not suitable for retrieval. We need to segment the document content. After dragging the file, the following interface appears:

#### Segmentation Settings

This is the text segmentation method. Below we will introduce general segmentation and parent-child segmentation.

- **General Segmentation:** Divides the article content into paragraphs. Each paragraph has some keywords automatically generated by Dify. When a user inputs a piece of text, the model will extract keywords and use these keywords to retrieve the knowledge base, returning blocks with the same keywords as reference materials for the model's reply, which are the recalled blocks.
- **Parent-child Segmentation:** Divides the text content into parent and child segments. The parent segment contains child segments. When retrieving, the content of the child segment will be retrieved, but the entire parent segment will be returned, so that the model can obtain the complete context. Here I recommend parent-child segmentation.

The maximum segment length and segment overlap length can be set as needed.

#### Indexing Method

That is, the way the model retrieves files. Here, high quality is recommended, because direct keyword matching has very low accuracy. The Embedding model below is a model for text processing. The function of this model is to process text. We can use the model provided in the API.

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/15.6bhbejfzlb.webp)

#### Retrieval Settings

![Dify tutorial screenshot](https://ChasePassion.github.io/picx-images-hosting/Dify教程/16.wisw418z5.webp)

Here, hybrid retrieval is recommended. Set the weight settings and Rerank model according to the type of your knowledge base, and set Top K and Score threshold. Here, my setting is Rerank model, Top K is set to 10, and Score is not enabled. Rerank can ensure that the first information the model sees is the most relevant, and the following two settings can ensure that the information obtained by the model is comprehensive and complete.
